# Ассистент парковки

Браузерный тренажёр парковки. Показывает траекторию движения автомобиля так же, как динамические линии камер кругового обзора (360°): залитая область, которую заметёт кузов при текущем угле поворота руля, траектории углов и колёс, поперечные метки дистанции и точка будущего удара.

Работает без сборки и без зависимостей: чистые HTML, CSS и JavaScript. Открывается двойным кликом по `index.html` или с GitHub Pages.

## Возможности

- **Физика конкретного авто.** Кинематическая «велосипедная» модель (на парковочных скоростях проскальзывания нет) и геометрия Аккермана для передних колёс. Максимальный угол колёс рассчитывается из паспортного диаметра разворота, колёсной базы и колеи, а положение руля — из числа оборотов от упора до упора.
- **12 пресетов** (от Smart до Ford F-150) плюс свой автомобиль: длина, ширина, база, колея, передний свес, диаметр разворота, обороты руля.
- **Подсказки как в камерах 360°:**
  - заливка коридора, который заметёт кузов (вперёд и назад);
  - метки 0.5 / 1 / 2 / 3 м от бампера (красный / жёлтый / зелёный, как у Toyota PVM и Nissan AVM);
  - траектории углов кузова и колей колёс;
  - точка первого касания, расстояние до неё и красная часть траектории после удара;
  - крайние траектории при руле до упора;
  - центр и радиусы поворота;
  - ультразвуковые парктроники (4 спереди и 4 сзади) с цветными зонами и звуком.
- **8 упражнений**, которые подстраиваются под габариты выбранного авто, в трёх уровнях сложности: параллельная, перпендикулярная, паркинг с колоннами, ёлочка 45°, узкий гараж, выезд из тесной параллельной, разворот в три приёма, свободная площадка.
- **Бордюр задевают только колёса**, а свес бампера проходит над ним, как в жизни. Стены, заборы, машины и колонны задевает кузов.
- **Редактор сцен:** стены, заборы, бордюры, машины, колонны, столбики, конусы, разметка, тротуар, газон и парковочное место-цель. Объекты можно перетаскивать, поворачивать и задавать им точные размеры.
- **Сохранение:** автоматически в `localStorage`, экспорт и импорт JSON, ссылка на сцену (сжатая, сцена хранится в `#` адреса).
- **Статистика:** число манёвров (смен направления), касания, время и пройденный путь. Последний манёвр можно отменить.
- **Виды:** свободный, следование за машиной и вид 360°, где машина всегда смотрит вверх.
- **Управление:** клавиатура, мышь или касание. На телефоне доступны экранный руль и педали.

## Управление

| Действие | Клавиши |
|---|---|
| Вперёд / назад | `W` `S` или `↑` `↓` |
| Руль | `A` `D` или `←` `→`; перетаскивание экранного руля |
| Руль прямо | `C` или двойной клик по рулю |
| Тормоз / медленно | `Пробел` / `Shift` |
| Отменить манёвр | `Backspace` или `Ctrl+Z` |
| Смена вида / вписать сцену | `V` / `F` |
| Масштаб / сдвиг | колесо мыши или щипок / перетаскивание |
| Редактор | `Q` `E` поворот, `Del` удалить, `Ctrl+D` копия, стрелки двигают объект, `Shift` отключает привязку |

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Ассистент парковки"
git branch -M main
git remote add origin https://github.com/<user>/parking-assist.git
git push -u origin main
```

Затем в репозитории откройте **Settings → Pages → Build and deployment**, выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`. Через минуту приложение будет доступно по адресу `https://<user>.github.io/parking-assist/`.

## Структура

```
index.html          разметка и подключение скриптов
css/style.css       стили (тёмная тема, адаптив под телефон)
js/geometry.js      векторы, полигоны, пересечения (SAT), лучи
js/vehicles.js      пресеты авто и расчёт угла колёс из диаметра разворота
js/car.js           кинематика, Аккерман, шаг симуляции с остановкой у препятствия
js/world.js         объекты сцены, столкновения, проверка цели
js/scenarios.js     упражнения под габариты авто и уровень сложности
js/trajectory.js    прогноз траектории и поиск первого касания
js/sensors.js       парктроники и звук (Web Audio)
js/renderer.js      отрисовка на canvas
js/editor.js        редактор сцены
js/app.js           состояние, цикл, ввод, панель, сохранение
```

Скрипты подключаются обычными тегами `<script>`, а не ES-модулями. Поэтому страница работает и при открытии файла напрямую (`file://`), где модули блокируются политикой CORS.

Габариты пресетов приблизительные и взяты из открытых источников. Для точной модели укажите паспортные данные своего авто в разделе «Габариты и рулевое».
